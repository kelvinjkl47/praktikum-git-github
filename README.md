1. Tujuan Praktikum

Praktikum ini bertujuan untuk mengenal Git dan GitHub serta mempelajari cara membuat repository, melakukan clone repository ke komputer, dan mengelola file menggunakan Git.

2. Langkah Praktikum

1. Menginstal Git pada komputer.
2. Mengatur nama dan email Git.
3. Membuat repository baru di GitHub.
4. Melakukan clone repository ke komputer menggunakan perintah git clone.
5. Masuk ke folder repository menggunakan perintah cd.
6. Membuat branch bernama main.
7. Membuat file README.md untuk dokumentasi praktikum.

3. Hasil Praktikum

Repository praktikum-git-github berhasil dibuat di GitHub dan disalin ke komputer menggunakan Git. Branch main juga berhasil dibuat. Selanjutnya, file README digunakan untuk menyimpan dokumentasi praktikum.

4. Kesimpulan

Melalui praktikum ini, saya mempelajari dasar penggunaan Git dan GitHub, mulai dari konfigurasi Git, pembuatan repository, clone repository, hingga pembuatan branch. Git dan GitHub membantu mengelola serta menyimpan perubahan file proyek.
